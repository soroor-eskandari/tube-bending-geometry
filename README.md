# tube-bending-geometry

## Streamlit thesis dashboard

This repository includes two Streamlit entry points:

- `app.py`: the thesis workflow dashboard covering data preparation, data
  augmentation, geometry prediction, QRF/HGP uncertainty estimation, and
  within-group variability analysis.
- `dashboard.py`: the earlier compact interval-prediction demonstrator.

Both apps read static CSV, Parquet, and JSON exports from the thesis pipeline;
they do not train models or run expensive inference during normal startup.

Run locally from the repository root:

```bash
uv sync
uv run streamlit run app.py
```

With `pip`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

The prediction and metric files are generated by the existing QRF and HGP thesis
pipelines. For Streamlit Community Cloud, set the app entry point to `app.py`.

### Thesis PDF assets

The app does not require the thesis PDF at runtime. To prepare static candidate
figure assets locally, copy the thesis PDF to `main.pdf`, install dependencies,
and run:

```bash
python scripts/extract_thesis_assets.py
```

This writes rendered candidate pages to `assets/figures/` and records their
origin in `assets/figures/asset_manifest.json`. Manual cropping is still
recommended before using these assets in a final presentation.
