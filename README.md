# tube-bending-geometry

## Streamlit thesis demonstrator

This repository includes a lightweight Streamlit dashboard for demonstrating
interval prediction results for rotary tube bending. The app reads static CSV
and JSON exports from the thesis pipeline; it does not train models or run model
inference.

Run locally from the repository root:

```bash
uv sync
uv run streamlit run dashboard.py
```

Expected static data files:

- `data/processed/geometry.csv`
- `data/processed/processed_bending_setup.csv`
- `src/pipeline/ml/qrf/results/models/**/test_predictions.csv`
- `src/pipeline/ml/qrf/results/models/**/all_group_predictions.csv`
- `src/pipeline/ml/qrf/results/models/**/metrics.csv`
- `src/pipeline/ml/qrf/results/models/**/metadata.json`
- `src/pipeline/ml/hgp/results/models/**/test_predictions.csv`
- `src/pipeline/ml/hgp/results/models/**/all_group_predictions.csv`
- `src/pipeline/ml/hgp/results/models/**/metrics.csv`
- `src/pipeline/ml/hgp/results/models/**/metadata.json`

The prediction and metric files are generated by the existing QRF and HGP thesis
pipelines. The `all_group_predictions.csv` files are static supplemental exports
used to display intervals for train groups without running inference inside the
dashboard. For Streamlit Community Cloud, set the app entry point to
`dashboard.py`.
